# Image Measure · 图像测量工具

纯前端、单文件、免构建的图像测量工具：导入照片 → 用已知长度标定比例尺 → 在图上画测量图形 → 导出结果。

- **在线使用**：https://536338958.github.io/Image-measure/
- **离线使用**：下载本仓库后双击 `index.html` 即可（除 PDF 导出外全部功能可离线运行）

## 能做什么

- **导入**：拖放、文件选择、`Ctrl+V` 粘贴；工程文件（`.json`）也能拖回来继续编辑
- **标定**：两点定标尺 + 输入真实长度与单位，之后所有读数自动换算；可锁定防止误改
- **12 种测量**：直线、角度、平行线间距、点到线距离、圆弧、圆（圆心+半径 / 三点定圆）、椭圆、矩形、多边形、样条曲线、辅助线
- **取点辅助**：端点 / 边中点 / 交点 / 延长线吸附；放大镜（触屏时显示在手指上方）；约束开关（平行垂直 + 自定义角度，画矩形时为正方形）
- **导出**：PNG 图片、PDF 报告（矢量、可分页）、CSV 测量表、JSON 工程文件
- **编辑**：选中后可拖动顶点 / 整体 / 标注，多边形可插入顶点，撤销重做 200 步
- **界面**：中英双语、亮暗主题、HiDPI 清晰、触屏手势（双指缩放、绘制中可撤销 / 完成 / 取消）

## 本地运行

不需要安装任何东西，也不需要服务器：

1. 下载或克隆本仓库
2. 双击 `index.html`

任何支持 Canvas 2D 的现代浏览器都可以。PDF 导出会从 CDN 加载 jsPDF，离线时该项不可用，其余功能不受影响。

## 技术要点

- 单文件、零后端、零构建；唯一外部依赖是 PDF 导出用的 jsPDF
- 所有几何点以**图像坐标**存储，绘制时才换算到屏幕，因此缩放、导出都不会失真
- Canvas 2D 绘制，位图按 `devicePixelRatio` 分配，高分屏 / 系统缩放下线条不发虚
- 放大镜不采样画布位图，而是套一层放大变换重绘同一套矢量命令，放大后依然锐利
- PDF 导出复用同一套 `renderShape` 绘制命令，输出矢量而非截图
- 数据只存在于当前浏览器内存里，不上传任何服务器
